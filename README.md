Entri untuk bounty "One Word, One Username, One Reward" di make.fun: program ini menulis username make.fun milik akun sendiri — satu kata, tanpa penjelasan — ke `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

Program menulis username ke `/output/entry.txt`, lalu membaca balik berkas tersebut untuk memastikan isinya persis sama, satu kata, 1–30 karakter, tanpa newline akhir.
